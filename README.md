# Agentic AI System

An intelligent Agentic AI System designed to perform tasks autonomously using AI agents, tools, and memory.

## Features
- AI-powered autonomous agents
- Task planning and execution
- Tool integration
- Memory management
- Interactive Streamlit interface

## Technologies Used
- Python
- Streamlit
- LangChain
- OpenAI API
- Agentic AI

## Installation

1. Clone the repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py

## Project Structure

- app.py
- requirements.txt
- config.py
- agents.py
- tools.py
- memory.py
- utils.py
